# Projeto Névoa

*[Em português, mais abaixo.](#português)*

A co-op FPS for 1 to 6 players against zombies, on a procedurally generated island, with light RPG and an anime look. The game speaks English and Portuguese.

## How to play

1. Open the [latest release](https://github.com/lc-leonardo/projeto-nevoa-releases/releases/latest).
2. Download the `ProjetoNevoa-...-win.zip` file.
3. Extract the folder. The game doesn't open from inside the zip.
4. Open `Projeto Névoa.exe`.
5. In the menu, **Install on this computer** puts the game with your programs and makes the shortcuts.

It runs on 64-bit Windows 10 and 11. Once installed, the game itself tells you in the menu when there's a new version.

The game has no digital signature. If Windows shows a protection warning, click **More info** and **Run anyway**.

## Hosting a server

Each release also has `ServidorNevoa-....zip`, the dedicated server of that version, for Windows or Linux, with Node.js 22.13 or newer. Open `start.bat` or `start.sh`, and its panel opens in the browser: worlds, settings, the match and its console. Players need the same version as the server. The zip's `README.txt` has the rest.

## Português

FPS cooperativo de 1 a 6 jogadores contra zumbis, numa ilha gerada por procedimento, com RPG leve e visual de anime. O jogo fala português e inglês.

### Como jogar

1. Abra a [versão mais recente](https://github.com/lc-leonardo/projeto-nevoa-releases/releases/latest).
2. Baixe o arquivo `ProjetoNevoa-...-win.zip`.
3. Extraia a pasta. O jogo não abre de dentro do zip.
4. Abra `Projeto Névoa.exe`.
5. No menu, **Instalar no computador** coloca o jogo junto dos seus programas e cria os atalhos.

Funciona no Windows 10 e 11, de 64 bits. Depois de instalado, o próprio jogo avisa no menu quando há versão nova.

O jogo não tem assinatura digital. Se o Windows mostrar um aviso de proteção, clique em **Mais informações** e em **Executar assim mesmo**.

### Hospedar um servidor

Cada versão tem também o `ServidorNevoa-....zip`, o servidor dedicado daquela versão, para Windows ou Linux, com Node.js 22.13 ou mais novo. Abra o `start.bat` ou o `start.sh`, e o painel dele abre no navegador: mundos, configurações, a partida e o console. Quem joga precisa da mesma versão do servidor. O `LEIA-ME.txt` do zip tem o resto.
