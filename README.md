# Projeto Névoa

FPS cooperativo de 1 a 6 jogadores contra zumbis, numa ilha gerada por procedimento, com RPG leve e visual de anime.

## Como jogar

1. Abra a [versão mais recente](https://github.com/lc-leonardo/projeto-nevoa-releases/releases/latest).
2. Baixe o arquivo `ProjetoNevoa-...-win.zip`.
3. Extraia a pasta. O jogo não abre de dentro do zip.
4. Abra `Projeto Névoa.exe`.
5. No menu, **Instalar no computador** coloca o jogo junto dos seus programas e cria os atalhos.

Funciona no Windows 10 e 11, de 64 bits. Depois de instalado, o próprio jogo avisa no menu quando há versão nova.

O jogo não tem assinatura digital. Se o Windows mostrar um aviso de proteção, clique em **Mais informações** e em **Executar assim mesmo**.
